# 🤖 AI Student Task Manager

An intelligent and modern **AI-powered Student Task Manager** built using **HTML, CSS, JavaScript, and Gemini AI API**.

This application helps students efficiently manage daily tasks, receive AI-powered study suggestions, improve productivity, and organize academic work effectively.

---

## 🚀 Live Features

✅ Add New Tasks
✅ Edit Tasks
✅ Delete Tasks
✅ Mark Tasks as Completed
✅ Task Counter (Total / Completed / Pending)
✅ Task Filter (All / Completed / Pending)
✅ Task Search Functionality
✅ Due Date Support
✅ Task Priority (Low / Medium / High)
✅ Progress Tracking Bar
✅ Dark Mode Support 🌙
✅ Local Storage Support
✅ Responsive Design (Mobile + Desktop)
✅ Enter Key Support

### 🤖 AI Features

✅ Gemini AI Integration
✅ AI Task Suggestions

## ⚙️ Installation & Setup

### Step 1: Clone Repository

```bash
git clone https://github.com/Gaurav-0911/student-task-manager.git
```

### Step 2: Open Project

Open the project folder in **VS Code**.

### Step 3: Create Config File

Create a file named:

```txt
config.js
```

Paste this code inside:

```js
const GEMINI_API_KEY = "YOUR_GEMINI_API_KEY";
```

### Step 4: Run Project

Use **Live Server Extension** in VS Code.
